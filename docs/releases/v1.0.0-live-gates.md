# AI-103 v1.0.0 Live Gate Checklist

Status as of 2026-07-27: not approved. This checklist is the required handoff for H1, H2, H3, and H4. Completing offline UAT does not satisfy these gates.

## Rules

- Do not create or select an Azure subscription on behalf of the learner.
- Do not accept billing, legal, or marketplace terms on behalf of the learner.
- Do not enter payment information.
- Do not run live deployment, live model calls, or live tests without explicit approval.
- Do not treat Azure credits, free monthly amounts, or budget alerts as a guarantee of zero cost.
- Do not create the final release commit until H4 is approved.

Allowed non-mutating checks after owner setup:

```powershell

```

Stop if `az account show` points to the wrong tenant/subscription, no budget exists, the region is unavailable, or quota is unknown.

## H2 — Live resource deployment

Required before any resource creation:

| Item | Status |
|---|---|
| H1 completed | Pending |
| Resource group prefix reviewed | Pending |
| SKUs and optional services reviewed | Pending |
| Expected cost reviewed | Pending |
| Tags confirmed: `project`, `purpose`, `owner`, `task`, `createdBy`, `deleteAfter` | Pending |
| Teardown command/path reviewed | Pending |
| Explicit deployment confirmation | Pending |

Safe preview command:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/azure/deploy.ps1 -Live -WhatIf -Confirmation "deploy AI-103 live lab" -Location <region>
```

Live deployment command, only after approval:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/azure/deploy.ps1 -Live -Confirmation "deploy AI-103 live lab" -Location <region>
```

Stop if the what-if output shows unexpected resources, missing tags, unsupported region/SKUs, provisioned capacity, or any cost owner ambiguity.

Required teardown command after any approved live deployment:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/azure/destroy.ps1 -Live -Confirmation "destroy AI-103 live lab" -ResourceGroupName <resource-group>
```

Stop release if destroy does not verify that the resource group is gone, or if any retained resource lacks owner, expected cost, and expiry.
